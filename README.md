# திருக்குறள்

Read the deck: [https://kirubasankars.github.io/thirukural/](https://kirubasankars.github.io/thirukural/)

The page is all 1,330 couplets with Solomon Pappaiah's commentary. Open **தேடு** and type a Tamil word, an English word (`rain`, `god`), a romanized word (`mazhai`, `kadavul`), or a verse number.

The Android app is attached to the [GitHub releases](https://github.com/kirubasankars/thirukural/releases).
